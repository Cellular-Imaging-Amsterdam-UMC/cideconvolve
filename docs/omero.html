BIOMERO and OMERO

CIDeconvolve is designed to be launched from OMERO through BIOMERO, with Docker images pulled or converted to Singularity/Apptainer on the compute side.

Configure the workflow

Point BIOMERO to this repository's config.yaml and expose w_cideconvolve in the Zarr workflow list.

Prepare the image

Use the published Docker tag or convert it to a local SIF for Slurm execution.

Run from OMERO.web

Select images, configure parameters, launch the Slurm workflow, and let BIOMERO upload results back to OMERO.

Why OME-Zarr?

Chunked pyramidal output is efficient for large microscopy data and preserves physical metadata, display windows, and provenance.
