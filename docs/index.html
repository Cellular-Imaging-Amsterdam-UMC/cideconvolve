GPU deconvolution for real microscopy data

Sharper volumes. Less waiting.

CIDeconvolve turns OME-TIFF and OME-Zarr microscopy images into physically informed deconvolved outputs using SHB-accelerated Richardson-Lucy, TV regularisation, sparse-Hessian priors, and CUDA-backed PyTorch.

What it writes

Outputs that viewers understand.

OME-Zarr outputs include NGFF multiscales, physical coordinate transforms, OMERO channel display settings, CIDeconvolve provenance, and OME-XML metadata for Bio-Formats/QuPath compatibility.

QuPath friendly

Physical pixel sizes, channel names, colors, and contrast windows are preserved for inspection and downstream analysis.

Large image ready

Streaming mode reads halo-extended tiles and writes chunked pyramids without materialising huge tilescans in memory.
