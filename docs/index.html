CIDeconvolve

CIDeconvolve is a GPU-assisted deconvolution workflow for 2D and 3D fluorescence microscopy. It reads common microscopy formats, builds a physical point spread function from image metadata or supplied optics, and writes OME-TIFF or OME-Zarr outputs for downstream viewing and analysis.

Ways to use it

Choose the interface that fits the work.

The same deconvolution engine is available from the desktop GUI, the command line, Docker containers, and OMERO-connected Bilayers workflows.

Desktop GUI

Open local files, Leica browser entries, OME-Zarr, and OMERO images when the optional readers are installed. Tune parameters, inspect channels and planes, compare source and result, and export current views or full time series.

Command line

Run the Bilayers wrapper or the focused CLI from scripts. Image metadata is used by default; explicit optics parameters are available for datasets with incomplete metadata.

Data handling

Metadata and large images are first-class concerns.

OME outputs carry physical pixel sizes, channel display settings, pyramids, and provenance where possible. Streaming mode processes halo-extended tiles and writes chunked output so large tilescans and time series do not need to be held in memory at once.

Viewer compatibility

OME-TIFF and OME-Zarr outputs are written for inspection in tools such as QuPath, OMERO, and Bio-Formats based viewers.

Reproducibility

Workflow parameters, source metadata, and output settings are preserved in provenance files or OME metadata where the format supports them.
