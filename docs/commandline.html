Scripts and local automation

Command line

There are two useful command-line surfaces: the full Bilayers workflow wrapper and the focused PyPI CLI.

Workflow wrapper

Use this when you want the same interface as Docker, Bilayers, and BIOMERO.

python wrapper.py ^
  --infolder ./infolder ^
  --outfolder ./outfolder ^
  --method ci_rl ^
  --iterations 60 ^
  --output_format ome-zarr

Focused PyPI CLI

Use this for lightweight local scripts that only need CI-RL on OME-TIFF or OME-Zarr inputs.

pip install ci-deconvolve
ci_deconvolve --input image.ome.tiff --output out ^
  --iterations 40 ^
  --output-format ome-tiff

Metadata policy

Image metadata wins by default. Command-line NA, wavelengths, pixel size, and refractive indices are fallbacks unless override flags are used.

Batch folders

The wrapper processes folders and writes deconvolved images, benchmark CSV files, montage images, and provenance metadata.

Outputs

OME-TIFF and OME-Zarr outputs preserve physical pixel sizes and channel metadata for QuPath, ImageJ/Fiji, and OMERO workflows.
