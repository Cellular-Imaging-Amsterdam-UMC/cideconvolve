Standard workflow interface

Bilayers integration

The workflow interface is defined in config.yaml. The launcher, Docker commands, Gradio/Jupyter generation, and BIOMERO parameter forms all use this source.

Validate and launch

python bilayers_cli.py validate
python bilayers_cli.py generate --cli
python launcher.py

Strict LinkML validation is available with pip install -r requirements_bilayers_validation.txt and python bilayers_cli.py validate --strict.

Beginner parameters

Essential optics and method choices are kept visible for day-to-day use.

Advanced parameters

Streaming, benchmark, expert 2D widefield, and solver tuning controls are grouped as advanced.

Interface images

Separate -gradio and -jupyter tags follow the Bilayers convention without changing the headless workflow image.
