GUI manual

Use the GUI for exploratory deconvolution, metadata inspection, parameter tuning, visual comparison, and batch export.

Install and run

pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
pip install -r requirements_gui.txt
python gui/gui_deconvolve_ci.py
Optional: add --movie to expose iteration movie export and --fitpsf to expose experimental PSF fitting.

Open images

Load OME-TIFF, OME-Zarr, regular TIFF, ND2, CZI, LIF, Leica browser entries, and OMERO images where optional dependencies are installed.

Tune and compare

Use synchronized original/deconvolved panes, channel controls, Z/T navigation, projection modes, 3D rendering, scale bars, and per-channel display scaling.

Export

Save current timepoints, full T-series, projections, view PNGs, batch jobs, OME-TIFF, and OME-Zarr with physical metadata preserved.

Iteration movies

The GUI can record convergence as MP4 and optional GIF outputs. This is useful for tuning iteration counts and showing how SHB-RL evolves over time.

  • Enable with python gui/gui_deconvolve_ci.py --movie.
  • Use convergence mode auto to stop once improvement stalls.
  • Use the run log and quality metrics to compare settings.
