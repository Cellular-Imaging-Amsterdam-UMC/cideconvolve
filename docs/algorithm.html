Under the hood

Algorithm notes

CIDeconvolve combines physical PSF generation, GPU FFT convolution, robust metadata handling, and several deconvolution objectives.

ci_rl

Richardson-Lucy with Scaled Heavy Ball acceleration. It keeps the familiar RL update but adds momentum to reach useful results faster.

ci_rl_tv

SHB-RL plus Total Variation regularisation. It is useful when high iteration counts would otherwise amplify noise.

ci_sparse_hessian

A variational sparse-Hessian method for filament-like or sparse structures where thin details matter.

PSF model

The PSF path uses microscope type, emission/excitation wavelengths, NA, lateral/axial pixel size, immersion/sample refractive indices, coverslip settings, confocal pinhole, and optional pixel integration.

  • Vectorial Richards-Wolf model for high NA settings.
  • Scalar model for lower NA settings.
  • Gibson-Lanni style optical path difference corrections.
  • 2D widefield auto mode collapses a physically generated PSF for single-plane data.

Streaming and tiling

Large images are processed as halo-extended XY tiles. Only the core tile is written to output, then pyramid levels are built from level 0.
