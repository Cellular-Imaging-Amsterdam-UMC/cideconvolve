Algorithm notes

How CIDeconvolve processes an image

CIDeconvolve combines a physical point spread function, FFT-based convolution, Richardson-Lucy style updates, optional regularisation, and OME-aware writing. This page summarizes the implementation in a form meant for users and workflow maintainers.

Processing overview

The input image is read as channels, Z planes, timepoints, and XY pixels. Metadata is used whenever possible for pixel spacing, emission and excitation wavelengths, numerical aperture, refractive index, microscope type, and confocal pinhole. Parameters entered in the GUI, CLI, or workflow wrapper act as fallbacks or explicit overrides depending on the selected option.

Read image and metadata

OME-TIFF, OME-Zarr, regular TIFF and optional microscopy readers are normalized into the internal axis order used by the solver.

Build the PSF

A physical PSF is generated from the microscope settings and voxel spacing. For 2D widefield data, the automatically selected mode uses a physically generated PSF adapted to single-plane processing.

Deconvolve each channel

The selected algorithm runs on GPU when available, with CPU fallback. Large images can be split into overlapping tiles.

Write OME output

Results are saved as OME-TIFF or OME-Zarr with physical metadata, channel display information, pyramids where supported, and CIDeconvolve provenance.

Point spread function

The PSF describes how an ideal point of light is blurred by the microscope. CIDeconvolve generates it from the available optical settings rather than requiring a measured bead PSF for routine use.

Microscope parameters

The PSF uses microscope type, NA, emission and excitation wavelengths, lateral and axial pixel size, immersion and sample refractive index, coverslip information, and confocal pinhole size when relevant.

Model choice

High-NA settings use a vectorial Richards-Wolf style model. Lower-NA settings can use a scalar model. Optical path difference corrections follow the Gibson-Lanni family of microscope PSF models.

Deconvolution methods

The solver works in the Fourier domain. Convolution with the PSF is represented by multiplication with the optical transfer function, so each iteration can reuse efficient FFT operations.

Accelerated Richardson-Lucy: ci_rl

The default method is Richardson-Lucy deconvolution with Scaled Heavy Ball momentum. The update remains multiplicative and positive like classical RL, but an extrapolated estimate is used before the forward projection.

p_k = x_k + alpha_k * (x_k - x_{k-1})
y   = H p_k
r   = observed / max(y, epsilon)
x   = p_k * H^T r * boundary_weight

The momentum factor starts conservatively and increases with iteration number. In practice this usually reaches a useful reconstruction with fewer iterations than plain Richardson-Lucy while keeping the same FFT cost per iteration.

Total variation regularisation: ci_rl_tv

This method adds a total variation correction after the accelerated RL update. TV regularisation discourages noisy pixel-to-pixel oscillations while preserving edges. For anisotropic 3D data, axial derivatives are scaled by the ratio between lateral and axial pixel spacing so that Z is not treated as if it had the same sampling as XY.

Sparse Hessian regularisation: ci_sparse_hessian

The sparse-Hessian method combines a data term from the PSF forward model with a prior that penalizes second-order structure. It is useful for sparse or filament-like samples where preserving thin structures is important.

loss = reg * poisson_data_term(Hx, observed)
     + (1 - reg) * sparse_hessian_prior(x)

sparse_hessian_reg controls the balance between data fidelity and regularisation. sparse_hessian_weight controls the balance inside the prior.

Stability and preprocessing

Several small implementation details help the iterative solver behave well on real fluorescence data.

Background floor

The automatic background estimate uses robust low-intensity statistics. It acts as a positivity floor and as a safe denominator for ratio calculations.

Initial estimate

The automatic start mode chooses between flat, observed, background-subtracted, low-pass, and hybrid initial estimates based on microscope type and robust image statistics.

Offset and prefilter

An automatic processing offset can stabilize very low-valued pixels. Optional prefiltering smooths in an Anscombe-like domain before deconvolution to reduce non-Poisson detector noise.

Boundary correction

Bertero-style boundary weights compensate for incomplete PSF support near image edges, reducing edge artefacts compared with uncorrected zero padding.

Convergence

Fixed mode runs the requested number of iterations. Automatic convergence monitors the I-divergence between the observed image and the current forward projection. When relative improvement becomes smaller than the configured threshold, the solver stops early.

I = mean(observed * log(observed / prediction) - observed + prediction)

Large images and time series

Large-image streaming processes one region at a time instead of materialising the whole result in memory. XY tiles are read with halo overlap so that deconvolution has context beyond the tile edge. Only the central tile core is written into the output. For OME-TIFF and OME-Zarr, pyramid levels are generated from the written level 0 data so the result remains usable in viewers that expect multiscale images.

For time series, the GUI and wrappers can save a selected T range and skip frames. This makes test exports practical before running a full acquisition.

Output data type

Float32 output preserves the numerical solver result directly. UInt16 output is available for smaller files and viewer compatibility. When converting to UInt16, the result is scaled from robust intensity limits instead of simply clipping high floating-point values.

Diagnostic metrics

Metrics are optional and are intended as diagnostics, not as a ground-truth quality score. For large images the calculation uses a deterministic sample, keeping at most 32 Z planes and 512 pixels in Y and X. Each sampled channel is normalized to the range 0 to 1 before metrics are calculated.

Detail energy

Measures how much Fourier power lies in higher spatial frequencies. A moderate increase often reflects sharper structures; very large increases can also indicate ringing or noise.

Bright detail energy

Applies the frequency measurement mainly to the brightest signal regions, which is often more informative for fluorescence images with dark background.

Edge strength

Uses average gradient magnitude to summarize sharper local transitions. It should be read together with the visual result.

Signal sparsity and robust range

Sparsity describes how concentrated the signal is. Robust range reports the 0.5 to 99.5 percentile spread, giving context for intensity redistribution.

Useful metric patterns are usually modest increases in detail energy, bright detail energy, and signal sparsity, with robust range used as context. Visual inspection and sample knowledge remain essential.
