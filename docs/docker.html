Reproducible containers

Docker images

The headless image is the workflow image. Optional Gradio and Jupyter images are built separately for interactive Bilayers-style use.

Headless

docker run --rm --gpus all ^
  -v /input:/data/in ^
  -v /output:/data/out ^
  cellularimagingcf/w_cideconvolve:v3.0.0

Gradio

docker run --rm --gpus all -p 7878:7878 ^
  cellularimagingcf/w_cideconvolve:v3.0.0-gradio

Jupyter

docker run --rm --gpus all -p 8888:8888 ^
  -v /data:/data/in ^
  cellularimagingcf/w_cideconvolve:v3.0.0-jupyter

Build locally

.\builddocker.cmd
.\builddocker_gradio.cmd
.\builddocker_jupyter.cmd

Tags are read from version.txt. Unqualified tags use PyTorch 2.13 with CUDA 13.2. The headless build also creates -cu130 fallback tags for clusters undergoing driver validation. A multi-stage builder compiles the optimized backend for SM 86, 89, 90, 100, and 120; the slim runtime contains the extension but no toolkit or compiler. Run python /app/cuda_smoke.py with GPU passthrough before promoting either image; the smoke test requires the optimized backend for all three solvers.

GPU note Install NVIDIA Container Toolkit or enable GPU support in Docker Desktop. Driver 595.45.04 or newer is recommended for CUDA 13.2; CUDA 13.x compatibility on older 580-series cluster drivers must be validated before deployment. Omit --gpus all for CPU-only runs.
